# CableMap

Validate a small AV signal path, explain broken connections and export a useful patch list.

This preserves the finalized portfolio brief without adding features. The learner explicitly approved this scope on 20 October 2026; the concept was originally agent-proposed, and that provenance is retained.

## The Unique Kernel
Explain why a particular connection cannot carry the declared signal, with the offending path visible. Unknown conversions stay unknown instead of being declared compatible.

## Who It's For
A community presenter arranging a small AV desk before an event, currently checking a hand-written patch list.

## The Core Loop
Select devices from a six-type authored catalog; connect declared input/output ports; inspect direction, compatibility and occupied-input errors; repair the path; save/reload locally; export a printable patch list and labels. A keyboard-accessible list editor accompanies the diagram.

## Inspiration & Identity
Clear, practical signal-path explanations. The learner requests clear visual feedback and a complete, demonstrable workflow. On 23 October the owner explicitly delegated the first-screen/layout decision to the agent; the chosen arrangement and visual style are recorded in devpost/prd.md as agent decisions. No further layout answer is needed. WireViz is a known adjacent documentation tool, not evidence that the underlying diagramming idea is novel.

## Why This Matters to the Learner
The user wants the finalized eight urgent applications built, deployed and verified by October24 IST. A personal motivation or learning outcome specific to AV work has not been supplied and is not invented here.

## What "Working" Looks Like
In a clean browser, build one valid presenter/projector/audio path, introduce an incompatible or already-occupied input, see a specific explanation, fix it and print a patch list that exactly matches the reviewed connections. Reload retains the local diagram. A public HTTPS site supports demonstration without account setup.

## The POC Boundary
Six declared device types; limited HDMI/USB/audio signal vocabulary; deterministic checks; local storage; diagram and keyboard list; printable export. User-entered metadata is unverified. No runtime AI or paid model dependency.

## Later
More verified device profiles and richer diagram layout, only after the complete bounded release.

## Explicitly Cut
No mains wiring, soldering, pin-level electrical advice, power capacity, phantom power, automatic hardware discovery or arbitrary adapter compatibility. These require information beyond the declared low-voltage signal model.
